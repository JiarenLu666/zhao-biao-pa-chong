# 泰兴招标网（okcis）侦察记录

## 结论

`https://taixingshi.okcis.cn/` 是“招标采购导航网”旗下的商业聚合站，不是政府官方发布平台。它适合作为**辅助发现源**：先从公开列表发现标题和链接，再回到江苏政府采购网或原公告核验；不替代省网主源，也不直接作为预算事实来源。

## 实测信号（2026-09-02）

- 首页 HTTP 200，`Content-Type: text/html; charset=GB2312`，页面标题为“泰兴招标网-泰兴市招标采购信息|泰兴建设工程项目|招标网”。
- `/sww/bn/` 公告列表 HTTP 200，静态 HTML，无验证码；页面显示 4,895 条、98 页、每页 50 条，分页链接形如 `1-50-4`、`2-50-4`。
- 列表页同时混有政府采购、工程施工、医疗设备、拍卖、企业询价等内容；首屏 50 条中可见视频拍摄、文化馆等目标候选，也有大量无关项目。
- 列表项提供标题、相对详情 URL、类别、日期；部分行显示类似 `88.73万` 的无标签金额，只能保存为 `budget_raw` 提示，不能直接当作预算金额。
- 抽取一条公开详情链接时返回 HTTP 200 的“请输入验证码”页面，表单为 `/php/checkUser/doVerify.php`，验证码为图片算术题。详情内容因此不能无人值守批量读取；不做 OCR、计算或第三方打码。
- `robots.txt` 对通用爬虫 `Allow: /`，同时禁止 `*.js`、`*.css`、`/login/` 及若干业务路径；`/sww/bn/` 未被禁止。robots 允许不等于站点承诺的高频访问额度，仍需低频运行。
- 响应头包含 WAF（`Server: wswaf`）及分钟/日访问计数 Cookie，说明应把请求预算控制在很低范围。

## 工程定位

项目已新增 `tender_monitor.sources.okcis_taixing`：

1. 解析静态列表并生成可入库的 `TenderRecord`，来源标记为 `okcis_taixing`。
2. 列表金额不带标签时强制保持 `UNKNOWN`，不重复省网中已经修正的“取第一个数字”问题。
3. 详情验证码页只记录为人工处理状态，不尝试绕过。
4. 配置默认每次至少间隔 15 秒并加 0–5 秒抖动，每次最多 2 页；正式运行应优先使用“最新/近三天”链接，避免抓 98 页历史数据。

离线解析已用实测页面结构复核：50 条列表项、4,895 条总数、98 页、2 条目标关键词候选；详情验证码门槛识别为真。未对该站点做翻页压力测试。
